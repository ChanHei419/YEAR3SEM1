How to Run:
1. Go to the 'Server' folder
  ->double-click 'RunServer.bat' 
    ->start the game server. *Keep this window open*.
2. Go to the 'Client' folder.
   ->Double-click 'TaikoGame.exe' to start Player 1 (Host).
    ->Double-click 'TaikoGame.exe' again to start Player 2 (Client) for testing online mode.
