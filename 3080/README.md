# IERG3080 — Software Engineering Group Project

**Taiko rhythm game** built as a group project (Group 21): a C# game client with an ASP.NET server for online multiplayer.

## Contents

| Path | Description |
| --- | --- |
| `IERG3080_Project_Group21/standalonePlayable/Client` | Playable game build (`TaikoGame.exe`) with client source |
| `IERG3080_Project_Group21/standalonePlayable/Server` | ASP.NET game server |
| `IERG3080_Project_Group21/ProjectReport_Group21.pdf` | Full project report |
| `IERG3080_Project_Group21/IERG3080_DEMO_group21.mp4` | Demo video |
| `code.cs`, `asm2.html` | Course exercises |

## How to run

1. Open the `Server` folder and double-click `RunServer.bat` — keep the window open.
2. Open the `Client` folder and double-click `TaikoGame.exe` for Player 1 (host).
3. Run `TaikoGame.exe` again for Player 2 (client) to test online mode.

## What this course covered

- Software engineering process: requirements, design, implementation, testing
- Client–server architecture and networked game state
- Working in a team with Git and code review
