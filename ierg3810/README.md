# IERG3810 — Microprocessor Systems

ARM firmware labs and a final project built with **Keil uVision** (C and assembly).

## Contents

| Folder | Focus |
| --- | --- |
| `lab-0` … `lab-2`, `1155212799_lab3` … `1155212799_lab5` | Progressive firmware labs: GPIO, timers, interrupts, peripherals |
| `Project_ASM` | Final project — assembly implementation |
| `1155212799_project` | Final project submission |
| `Project.uvprojx` | Keil uVision project files |

> Note: `.o`, `.d`, `.crf`, `.lst`, `.map`, `.axf`, and `.hex` files are compiler/linker build outputs generated locally by Keil.

## What this course covered

- Microprocessor architecture and embedded C
- GPIO, timers, and interrupt handling
- Assembly language programming
- Debugging on hardware with Keil uVision
