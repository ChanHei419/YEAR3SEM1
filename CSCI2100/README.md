# CSCI2100 — Data Structures

Assignments from CUHK's Data Structures course, implemented in **C**.

## Contents

| Assignment | Topics | Files |
| --- | --- | --- |
| `2100asm1` | Stack, string algorithms | `q1/stack.h`, `q2/palindrome.c` |
| `2100asm2` | Linked lists, symbol tables, simulation | `q8/list.c`, `q9/list.c`, `q9/symtab.c`, `q9/prizeFnT.c` |
| `2100asm3` | Sorting and advanced list operations | `mergesort.c`, `list.c` |

## What this course covered

- Abstract data types: stacks, queues, linked lists
- Complexity analysis (Big-O) and algorithm design
- Merge sort and other sorting algorithms
- Memory management and pointers in C
- Simulation problems with structured input/output
