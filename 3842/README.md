# IERG3842 — Mobile Application Development (Android / Kotlin)

Android lab exercises written in **Kotlin**, covering the fundamentals of modern mobile app development.

## Contents

| Folder | Focus |
| --- | --- |
| `lab1` | Android project setup and basic activities |
| `lab2` / `IERG3842_Lab2` | Layouts, UI components, and activity lifecycle |
| `lab3` | Intents, navigation, and passing data between screens |
| `lab4` / `lab4r` | App architecture, persistence, and UI state |

## What this course covered

- Kotlin syntax and Android Studio workflow
- Activity lifecycle, layouts, and responsive UI
- Intents, navigation, and data passing
- Gradle build configuration and app packaging
